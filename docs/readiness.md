# Readiness – Kraftly

Fyll i kolumnen **Status** utifrån vad ni kan visa som bevis. Använd:

- `klart`
- `känd brist`
- `saknas`
- `utgår (beslut 12/10)` för det som ströks ur kursen
- `v.12` för release-raden

Raderna ska markeras `saknas` där status inte kan avgöras från tillgängliga bevis. Ändra dem först efter att ni har kontrollerat bevisen.
