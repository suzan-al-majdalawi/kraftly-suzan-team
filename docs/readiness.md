# Readiness – Kraftly

Fyll i kolumnen **Status** utifrån vad ni kan visa som bevis. Använd:

- `klart`
- `känd brist`
- `saknas`
- `utgår (beslut 12/10)` för det som ströks ur kursen
- `v.12` för release-raden

Raderna är initialt markerade `saknas` där status inte kan avgöras från tabellen. Ändra dem efter att ni har kontrollerat bevisen.
